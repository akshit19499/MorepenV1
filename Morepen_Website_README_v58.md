# Morepen Website v58

This build continues the approved v57 design system and applies two focused numbering refinements.

## Changes in v58
- Home / company foundation tiles: serial numerals are now large, regular-weight and smoke grey for stronger visual hierarchy.
- R&D `Science at work` tiles: the secondary labels (PROCESS / ANALYTICAL / QUALITY / CONTINUOUS) have been removed. The hierarchy is now serial number -> main title -> supporting paragraph, with spacing aligned to other numbered tile systems across the site.
- No copy, routing, imagery, navigation or functional changes were made.
